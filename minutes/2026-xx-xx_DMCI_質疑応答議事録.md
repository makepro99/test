## 第2部　整理（論点別）

### A. 技術的な最大の論点 —「打撃打設 vs プレボーリング」

**フィリピン側の実務と本工法の前提が食い違っている、本日最大の争点。**

| 項目 | 内容 |
|---|---|
| 本工法の前提 | 杭頭の鉄板を損傷させないため、**プレボーリング必須**（打撃打設は不可） |
| フィリピンの実務 | **打撃（ハンマー）打設が標準**。プレボーリングはほぼ使わない |
| DMCI の懸念 | **プレボーリングはコスト高**。「打撃打設で使えないなら、メリットは何か」 |
| NSW の回答 | 杭頭はつり（hacking）不要、工期短縮・省人化、接合部がより剛、**騒音・振動が出ない** |
| 未解決 | **コスト増（プレボーリング）を上回るメリットの定量的提示ができていない** |

→ **この論点の解消が採用可否を左右する最重要課題。**

### B. 適用範囲についての質疑まとめ

| 質問 | 回答 |
|---|---|
| 角杭（プレキャスト矩形中実杭）に使えるか | 使える。ただし**杭頭に鉄板を取付**＋**プレボーリング**が条件 |
| オフショア（桟橋・港湾）に使えるか | **適用可能** |
| PHC/PRC（スパン杭）専用か | **各種の杭タイプに適用可** |
| 対応最大径 | **日本のプレキャスト杭は最大 φ1200mm** |
| φ2.5m 案件（送電鉄塔・高さ55m）への対応 | φ1.2m で本数を増やす形。**強度が高いので本数は減らせる**が、**構造計算・別途検討が必要** |
| 杭長 30m は全長プレキャストか | 否。**約10m 単位で継いでいく**。現場継手可 |

### C. 接合・防食のディテール

- **杭頭ディテール**: 杭頭に**トッププレート（鋼板）**、**鋼製リングとコンクリート杭を工場で機械的（メカニカル）に接合**。接合部形状は**リブ**。
- **既存工法との差**: 従来は杭頭をはつって鉄筋を露出させ基礎鉄筋と接合（時に溶接）。本工法は**はつり不要・より剛な接合**。
- **防食**: **スタッドはコンクリート中に埋設されるため露出せず錆びない**。露出する要求がある場合は**露出前に防錆処理**が必要。**鉄筋の特殊防錆仕様にも対応実績あり**。
- **プレボーリング孔の隙間処理**: **プレボーリング後速やかに建て込み、地盤と杭の間に混和材（セメント系スラリー相当）を注入**。注入は**建て込み後**。

### D. 商務・体制

- **Trisco の役割は「スタッドの施工（設置）のみ」**。プレボーリングや杭製造・杭施工は含まない。
- **スパン杭は日本から調達**（フィリピン国内のスパン杭メーカーは限定的、通常はマレーシア産）。
- **Trisco はフィリピンで認定（accreditation）取得済み**。
- **流通・施工体制は未確定**。次回訪問で協議。
